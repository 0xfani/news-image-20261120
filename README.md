One picture of Friday 20 November 2026: the day's world news on a single 1024×1024 front page. A big dated masthead, a red standfirst naming the leads, region and field bars, the day in numbers, a UTC timeline, 15 illustrated story cards with minimal flat pictograms and per-card source labels, a world map with numbered pins, an "Also on" briefs list, and a green date-check box stating that every story happened or was first reported on 20 November 2026. Stories were gathered from the morning RSS feeds of BBC, Guardian, NYT, Al Jazeera, France 24, Euronews, CNA, Anadolu, Straits Times, RNZ, ABC and others, keeping only items published on 20 November in UTC.

The repository holds the finished page as `entry.png`; `main.py` copies it to the output folder. No network, no randomness: every run writes identical bytes.

## Run it

```sh
python main.py   # writes entry.png to $MAKEFUN_OUTPUT_DIR, or /output in the make.fun sandbox
```
